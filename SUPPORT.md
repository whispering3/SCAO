# Support

## Before opening an issue

Run `scao-doctor` and include its output, your SCAO and PyTorch versions,
Python version, device/CUDA details, and a minimal reproducible example. For
performance reports, attach the JSON generated by
`scao-preconditioner-bench --json result.json`.

## Issue categories

- **Bug:** a minimal reproduction and expected versus actual behavior.
- **Performance regression:** baseline and candidate benchmark JSON files on
  the same hardware and software stack.
- **Feature request:** workload, expected API, and compatibility impact.
- **Security issue:** follow [SECURITY.md](SECURITY.md); do not report it
  publicly.

Community support is best-effort. Production users should validate optimizer
behavior against a matched AdamW baseline for their workload before rollout.
